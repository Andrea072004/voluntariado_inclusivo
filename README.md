# 🤝 Voluntariado Inclusivo – Plataforma Web con Flask y Machine Learning

📌 **Proyecto académico para promover la inclusión de personas con enfermedades crónicas y discapacidad de desarrollo en programas de voluntariado.**  
Desarrollado con tecnologías modernas como **Flask, HTML/CSS/JS, Firebase** y un **modelo de Machine Learning** en Google Colab.  

---

## 🎯 Objetivo del proyecto

Desarrollar una plataforma web inclusiva que:

- Permita el registro y personalización del perfil del usuario.
- Recomiende oportunidades de voluntariado adaptadas a sus intereses y capacidades.
- Sea accesible para personas con discapacidades (modo alto contraste, texto ajustable).
- Aplique un modelo predictivo que mejore la experiencia y retención de los voluntarios.

---

## 🧠 Tecnologías utilizadas

| Tecnología        | Uso principal                                      |
|-------------------|---------------------------------------------------|
| 🐍 **Python + Flask** | Backend y rutas principales                    |
| 🧠 **Google Colab**  | Entrenamiento del modelo de Machine Learning    |
| 🌐 **HTML, CSS, JS** | Interfaz web y validaciones en tiempo real      |
| 🔥 **Firebase**       | Autenticación y base de datos en tiempo real    |
| 📊 **Scikit-learn**  | Algoritmo de clasificación (Random Forest, Árbol de decisión) |

---

## 🧩 Módulos del sistema (PMVs)

- 🔐 **PMV1**: Registro, inicio de sesión, perfil, seguridad.
- 🎯 **PMV2**: Intereses, filtrado personalizado, favoritos, notificaciones.
- 🧩 **PMV3**: Accesibilidad visual y seguimiento del uso.
